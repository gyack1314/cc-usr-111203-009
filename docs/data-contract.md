# 有限灾害因子与路网

状态概率是精确分数，因子独立，状态内部不同道路共享同一次取值。allowed是因子到允许状态集合的映射，列出多个因子表示逻辑且；未列出的因子不限制该道路，空集合代表该道路在该条件下永不可通。道路为无向平行边，edge_id不可合并成端点对。fortifications每一方案独立与未加固基准比较，不在方案之间累计。

精确模式终端成功/失败概率与因子失败后验都可为有理数，零概率状态不贡献质量但仍属于配置身份。抽样副本中每方案共享完整因子状态，差值D为加固成功指示减基准成功指示；标准误为D样本标准差除sqrt(B)，不是边概率传播。后验抽样若没有观察到失败只能报抽样无法估计，不能证明真失败概率为零。

`inspect`显示当前原始摘要，不覆盖资料。`invalid-`前缀文件为不合法资料，其他变体使用相同字段保留业务边界。来源字节SHA-256随摘要输出，后续结果应同时标明输入身份、量纲和适用范围。

# 相关灾害风险分析（risk）

`climate_data.risk`在冻结路网上比较基准（不加固）与每个加固方案的终端连通风险，只读计算，不导航、不操作交通设施。

- 成功判据：配置的全部终端在剩余可通图中属于同一连通分量（并查集判定，不只检查度数非零）。
- 精确模式（`risk/exact.py`）：概率与后验均为`fractions.Fraction`精确有理数。递归对因子状态分支，记忆化合并键为“当前连通分量划分 + 每条未决道路的剩余允许状态约束”。仅坏边数相同不构成等价，绝不合并。预算（`exact_state_budget`）耗尽时只输出已证明概率质量、访问状态数与`budget_exhausted`终止状态，连通概率与后验返回空值，不给精确结论。
- 小因子空间（不超过预算）另跑朴素全枚举核对记忆化解，核对结果写入`enumeration_cross_check`；零概率状态仍计入访问身份但不贡献质量。
- 后验：`P(因子=状态 | 失败) = P(因子=状态 且 失败) / P(失败)`，通过把该因子钉住为指定状态后精确重算失败质量得到。失败概率为零时条件后验不可定义，报告`failure_probability_zero`，不用先验替代。
- 蒙特卡洛（`risk/montecarlo.py`）：固定`seed`，基准与全部加固方案共用同一组因子状态抽样（`matrix_sha256`标识抽样矩阵）。改善量按逐样本成功指示差`D_k`计算，标准误为`D`的样本标准差除以`sqrt(B)`；两个边际估计共享抽样、存在协方差，不能把各自标准误相加。抽样结果统一标记`is_exact=false`。
- 失败代表情景（`failure_previews`）只用于解释，不是对全部风险的覆盖证明；报告同时给出每个情景的终端连通分区与加固假设，保证可独立复演。
